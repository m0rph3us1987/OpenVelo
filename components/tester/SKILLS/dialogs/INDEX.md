# Dialogs

Procedures for native and toolkit file/folder chooser dialogs — GTK
(GtkFileChooser), Qt (QFileDialog), Avalonia, and similar. These dialogs are a
frequent source of trial-and-error: the confirm button label varies ("Open",
"Select", "Choose", "OK"), the path can be typed or navigated, and the button
often stays disabled until a valid target is highlighted. The skills here give
a deterministic path through them.

# Skill: Folder open dialog

Category: [dialogs](INDEX.md) · Base: [/SKILLS](../INDEX.md)

Pick an existing folder in a "Select Folder" / "Open Folder" dialog.

## Rules of thumb

1. Create the target folder beforehand if it doesn't already exist.
2. Prefer folders under the persistent data directory (e.g. `/data/...`).
3. Always use the mouse/click interactions to navigate through the folder structure. Do NOT use keyboard shortcuts (like `CTRL+L` to type paths) to bypass graphical navigation. The use of `CTRL+L` is strictly forbidden.
4. Double-click folders in the list to enter them.
5. Once the target folder is open, click **Select** (or the confirm button) in the lower right to confirm.

## Example — selecting `/data/backups`

1. Click on the root directory or persistent directory in the sidebar/list.
2. Double-click **data** in the folder list.
3. Double-click **backups** in the folder list.
4. Click **Select** in the lower right.

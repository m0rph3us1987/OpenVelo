## Instructions

Analyze the build output.
1. Determine if the error is caused by missing build tools, libraries, or dependencies (e.g., "command not found", missing header files, missing libraries, "dotnet: not found", "npm: not found").
2. Determine if the error is due to missing project files (e.g. "package.json not found", "no such file or directory pom.xml", "no sln file").
3. Determine if the error is an actual logic or syntax error in the code (e.g., compilation errors, syntax errors, "ReferenceError").

If the error is due to missing tools or libraries:
- Update the setup script at {{SETUP_SH_PATH}} to install the missing tools.
- The script must be non-interactive (use `export DEBIAN_FRONTEND=noninteractive`, `apt-get install -y`, etc.).
- You MUST prepend `#!/bin/bash` to the script if it's new.
- If you made changes to the setup script, output exactly: SETUP_ADJUSTED

If the error is due to missing project configuration files (e.g., package.json, pom.xml) AND the repository is empty (Repo is empty: true):
- Output exactly: EMPTY_PROJECT

If the error is an actual code error or build logic error that cannot be fixed by installing tools:
- Do NOT adjust the setup script.
- Output exactly: BUILD_ERROR

## Running Background Servers
If you need to start a web server or dev server (e.g., `npm run dev`) to manually test your code, **do NOT run it natively** (e.g. `npm run dev` or `npm start &`). Running a server natively blocks your bash tool and causes your turn to timeout and fail.
You MUST use `/app/mcp/run.sh <command>` (e.g., `/app/mcp/run.sh npm run dev`). This correctly detaches the process and logs its output so your tool call returns immediately.
To stop a background server, use `/app/mcp/stop.sh <pattern>` (e.g., `/app/mcp/stop.sh node`). Never use `pkill` or `killall` directly.

## Git Ignore
You MUST always ensure that `.kilo/` is added to the repository's `.gitignore` file. If `.gitignore` does not exist, create it and add `.kilo/`. If it exists, append `.kilo/` if it is not already present.

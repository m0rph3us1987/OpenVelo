### Live plan (web-UI)

The OpenVelo web-UI renders a live "Plan" panel that mirrors the
Kilo `todowrite` tool. Populating it is **required**, not optional —
the user watches it to see real progress through the plan.

Before you start coding, call `todowrite` once with the list of
logical units of work you intend to do. Each unit becomes one entry
in the panel. Pick the granularity that makes the progress legible
(e.g., one todo per top-level `## N.` section of the plan, per file
or file group, or per logical chunk you can complete in one coherent
step). All items start with `status: "pending"`.

As you work, call `todowrite` again each time you switch tasks: mark
the finished item `completed`, set the next item to `in_progress`. Only
one item should be `in_progress` at a time.

Add new todos if the work expands (e.g., a test failure surfaces a
follow-up fix you didn't anticipate). Mark skipped items
`status: "cancelled"`.
